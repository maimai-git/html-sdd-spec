# 状态规范

由 `html_sdd/assets/statuses.json` 生成，请勿手改；修改字典后运行 `python3 tools/sync_statuses.py`。

| 语义色 | 文字色 | 背景色 |
|---|---|---|
| done | `#166534` | `#ecfdf3` |
| progress | `#1d4ed8` | `#eff6ff` |
| wait | `#854d0e` | `#fff7e6` |
| review | `#6d28d9` | `#f5f3ff` |
| blocked | `#b42318` | `#fef3f2` |
| neutral | `#475569` | `#f1f5f9` |

| 板块 | 允许的状态 |
|---|---|
| metadata | 方案待对齐、方案已对齐、开发中、验证中、待上线、已上线、阻塞、已取消、待核实 |
| agents | 待开始、进行中、阻塞、已完成、已取消、待核实 |
| requirements | 待拆分、待确认、编码 READY、进行中、待复核、待验收、阻塞、已完成、已取消、待核实 |
| plans | 待拆分、待确认、编码 READY、待开始、进行中、待接入、待执行、待复核、待验收、阻塞、已完成、已取消 |
| apis | 待部署、已部署、待验证、已验证、阻塞、不适用、待核实 |
| existingInterfaces | 待部署、已部署、待验证、已验证、阻塞、不适用、待核实 |
| tables | 待部署、已部署、待验证、已验证、阻塞、不适用、待核实 |
| architecture | 待设计、设计中、待复核、已确认、阻塞、已取消、待核实 |
| configs | 待配置、待执行、已执行、待验证、已验证、阻塞、不适用、待核实 |
| evidence | 待核实、已记录、已验证、失败、已失效 |
| questions | 待确认、核实中、阻塞、已确认、已解决、已关闭、已完成、已取消、待核实 |
| developmentStatus | 已完成、部分完成、未开发 |
| acceptance | 待验证、待验收、验证中、已通过、未通过、阻塞、不适用、待核实 |

`status` 保存短枚举，`statusNote` 保存说明。新文档启用 `metadata.statusPolicy=strict`；旧文档默认 legacy，未知长句警告并显示灰色“待核实”，不从关键词猜状态。排期与开发状态始终严格；开发状态不代表部署或验收。
