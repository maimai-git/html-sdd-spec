# 公共定义与引用实施计划

目标：公共参数和业务规则只维护一次，JSON 和单文件 HTML 保留引用，AI 查询与浏览器详情按需展开。兼容 0.1 的内联格式，不使用 gzip、Base64、外部数据请求或新运行时依赖。用户已确认本轮三项方案；不提交、推送或全局安装。

设计：新增可选 definitions.fields、definitions.rules 两个本地字典。fields 的值为字段对象或字段对象数组，rules 的值为字符串或字符串数组。apis / existingInterfaces 的 request、response、rules 数组可在原位置写纯 {$ref:"#/definitions/fields/名称"} 或 rules 引用，数组定义原位展开。只支持一次本地引用，不支持覆盖、跨文件、远程引用和定义内互引；名称遵循 JSON Pointer ~0/~1 转义。例子中的 $ref 是业务数据，不解析。只有完全相同、重复使用且净节省空间的字段/规则才自动提取。

字段职责：summary 用途、current 现状、rules 约束、progress 进展、note 例外/备注、evidenceIds 证据引用；不自动删改既有语义相似文字，不合并代码/部署/验收状态。

## 任务与验收

- [x] 1. references.py + tests/test_definitions.py：先写解析/缺失/错类型/覆盖/互引/原位数组/不改输入/转义测试，再实现统一解析器；checker、renderer、context、diff 接入。diff 同时报告定义和受影响接口；--full 展开目标合同，预算不足明确报错。
- [x] 2. templates/console.html 与打包模板同步：浏览器只在打开详情时展开引用，数据区仍紧凑。测试本地打开、参数顺序、规则、原生路径查找、缺失引用和反注入。
- [x] 3. reuse.py + CLI reuse：默认预览，--output 显式写新文件；完全相同内容按净收益提取，可重复运行且不改状态/路径/空值/示例/权限说明。加入语义等价、幂等、差异约束与 CLI 失败测试。
- [x] 4. schema、SPEC、README、Skill 按需参考更新；迁移公开示例，再对资产库当前事实源生成候选；确认引用展开后与原文一致、没有并发更新才替换。迁移保留备份。
- [x] 5. 全套单测、真实浏览器和已授权审核者独立复核；报告净体积收益、兼容性与未执行事项。

重点边界：同名字段不同where/required/type不合并；显式null/0/false不删；空或缺失定义不能解释为无参数/无规则；公共定义改变必须在diff和当前合同中可见；单任务查询不能泄漏整个定义库；UI不重复内嵌展开后的全量数据；共享工作区改动不覆盖。
