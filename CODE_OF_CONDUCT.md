# Contributor Covenant Code of Conduct

## Our pledge

We want this project to be a welcoming place for people with different backgrounds and levels of experience. Contributions should be judged by their clarity, usefulness, and respect for the project scope.

## Expected behavior

- Use clear, constructive language.
- Explain tradeoffs and compatibility impact.
- Respect different viewpoints and experience levels.
- Keep examples and issue reports free of secrets and private data.

## Unacceptable behavior

Harassment, personal attacks, discrimination, doxxing, publishing private information, and deliberate exposure of credentials are not acceptable.

## Enforcement

Report conduct concerns privately to the repository maintainers. Maintainers may edit, close, or remove content that violates this code or creates a security risk.
