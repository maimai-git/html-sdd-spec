# 订单状态筛选发布示例

这个示例演示如何在同一个需求目录里记录接口改动、数据库索引和配置开关。先创建订单筛选索引，再打开筛选开关，最后验收订单列表。

下载仓库后，用浏览器直接打开 [方案对齐.html](方案对齐.html)。在「上线配置」点击相对路径，即可打开对应文件。服务名、数据库和配置值均为演示数据。

| 文件 | 内容 |
| --- | --- |
| [方案事实源.json](方案事实源.json) | 需求、接口、数据表、排期及清单引用 |
| [上线配置.properties](上线配置清单/上线配置.properties) | 按服务和 Apollo 配置位置分段的嵌套 YAML，每项写明默认值和值来源 |
| [上线SQL.sql](上线SQL清单/上线SQL.sql) | PostgreSQL 组合索引，以及目标库、前置条件、执行和验收说明 |

在仓库根目录用当前源码检查并重新生成页面。

```bash
python3 -m html_sdd check 'examples/订单筛选发布/方案事实源.json' --release
python3 -m html_sdd render 'examples/订单筛选发布/方案事实源.json' --output 'examples/订单筛选发布/方案对齐.html'
```
