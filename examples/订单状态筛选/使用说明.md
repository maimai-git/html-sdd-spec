# 订单状态筛选

这是一个虚构示例。原有订单列表返回全部状态，本次增加按状态筛选。示例记录的是代码已完成、测试环境还待部署的阶段。

## 跑一遍

在 HTML SDD Spec 源码仓库根目录安装当前版本，创建一个临时项目。

```bash
python -m pip install .
demo_dir="$(mktemp -d)"
sample="$PWD/examples/订单状态筛选/方案事实源.json"
html-sdd init "$demo_dir/html-sdd-spec/订单状态筛选"
cd "$demo_dir/html-sdd-spec/订单状态筛选"
cp "$sample" 方案事实源.json
```

检查复制进去的[示例 JSON](方案事实源.json)，生成页面并盘点剩余工作。

```bash
html-sdd check 方案事实源.json
html-sdd render 方案事实源.json --output 方案对齐.html
html-sdd summary 方案事实源.json
html-sdd context 方案事实源.json API-001 --role executor --full
```

打开 `方案对齐.html`，从「需求」看验收标准，到「排期」看执行人，再到「接口」看筛选参数。摘要应列出 **PLAN-002 测试环境验证、AC-002 筛选验收、API-001 待部署**。

## 更新进展

测试环境部署并验证后，在事实源更新接口、验收和任务状态，附上对应环境的验收结果，再生成 HTML。若后续另做批量导出，在项目根目录的 `html-sdd-spec/` 下新建「订单批量导出」目录，引用旧方案并重新核对当时的代码和环境。
